# Modern Roblox Social HUD

A sleek black and red social HUD compatible with Xenomorph chat systems, designed for games like Mic Up.

## Features
- Executor detection displayed above players' heads
- Modern black & red UI theme
- Voice activity indicators
- Xenomorph chat compatibility
- Works with any executor

## Installation
1. Copy the script from `src/main.lua`
2. Execute in any Roblox game
3. Press `H` to toggle visibility

## Supported Executors
- Synapse X
- ScriptWare  
- KRNL
- Fluxus
- Electron
- And more...
